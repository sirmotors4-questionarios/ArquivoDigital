Ligar ao Power Automate

Introduza a URL do fluxo HTTP de consulta. A URL ficará guardada apenas nesta sessão do navegador, não no GitHub.

Esta URL permite consultar dados a quem a possua. Evite usar este método com documentos sensíveis. Não activa escrita no Excel.

A URL de actualização deve apontar para um fluxo que apenas cria pedidos na lista de controlo, nunca actualiza directamente o Excel. A configuração da URL não confirma que o fluxo esteja acessível; os erros HTTP serão apresentados ao enviar. Ao enviar, a operação fica pendente até confirmação do processador.
